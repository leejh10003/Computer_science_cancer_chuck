# LLM 모델 발달사와 최신 동향을 파악하기 위한 질문

## 조사 목적

LLM의 계보를 단순 연표가 아니라 기술적 전환점, 학습 방식, 제품화, 생태계, 안전과 정책의 상호작용으로 이해하고, 기준일 이후에도 반복 점검할 수 있는 조사 질문을 제공한다.

## 1. 범위와 핵심 개념

1. 이 조사에서 LLM을 어떤 기준으로 정의하고, 언어 모델·파운데이션 모델·멀티모달 모델과 어떻게 구분할 것인가?

   답변:

   - 언어 모델은 언어 토큰의 구조와 관계를 학습하고, 이를 바탕으로 언어를 이해하거나 생성하는 모델이다.
   - 멀티모달 모델은 텍스트·이미지·음성 등 서로 다른 둘 이상의 표현 형식을 처리하는 모델이다.
   - 파운데이션 모델은 광범위한 데이터로 사전학습되어 여러 과제에 적용할 수 있는 기반 모델이다.
2. 모델의 “발전”을 규모, 성능, 효율, 신뢰성, 접근성 가운데 어떤 지표로 평가할 것인가?
3. 사전학습, 미세조정, 지시학습, 선호학습, 추론 단계 연산을 각각 어떻게 정의할 것인가?
4. 폐쇄형 모델과 오픈 웨이트 모델을 비교할 때 라이선스, 재현성, 수정 가능성을 어떻게 구분할 것인가?
5. 발표일, 기술 보고서 공개일, API 출시일, 오픈 웨이트 공개일 중 연표의 기준일은 무엇으로 삼을 것인가?
6. “최신”의 시간 범위를 최근 3개월, 6개월, 1년 중 어디까지로 정할 것인가?

## 2. 초기 언어 모델에서 신경망 시대로

1. 통계적 언어 모델은 언어를 어떤 방식으로 표현했고 무엇에 한계가 있었는가?
2. 분산 표현과 신경망 언어 모델은 희소성 문제를 어떻게 바꾸었는가?
3. 순환 신경망, LSTM, GRU는 긴 문맥 처리에서 어떤 진전을 만들었는가?
4. seq2seq와 어텐션은 기계번역 및 생성 과제의 구조를 어떻게 바꾸었는가?
5. 서브워드 토큰화는 어휘 크기, 다국어 처리, 희귀어 처리에 어떤 영향을 주었는가?
6. 이 시기의 발전 중 오늘날 LLM에도 그대로 남아 있는 핵심 아이디어는 무엇인가?

## 3. Transformer와 사전학습 패러다임

1. Transformer는 이전 순차 모델의 병목을 어떤 구조적 선택으로 완화했는가?
2. 인코더형, 디코더형, 인코더-디코더형 모델은 어떤 과제와 학습 목표에서 갈라졌는가?
3. 자기지도 사전학습과 전이학습은 NLP 개발 방식을 어떻게 변화시켰는가?
4. 자동회귀 언어 모델링과 마스킹 언어 모델링의 장단점은 무엇인가?
5. 문맥 내 학습과 프롬프트 기반 사용은 모델 활용 방식을 어떻게 바꾸었는가?
6. 주요 전환점으로 선정할 모델은 무엇이며, 선정 기준과 제외 기준은 무엇인가?

## 4. 스케일링, 데이터, 학습 인프라

1. 모델 크기, 데이터 양, 학습 연산량 사이의 관계는 시대별로 어떻게 이해되어 왔는가?
2. 데이터와 파라미터 배분에 관한 스케일링 관점은 어떻게 변화했는가?
3. 고품질 데이터 선별, 중복 제거, 합성 데이터가 성능과 다양성에 미치는 영향은 무엇인가?
4. 데이터 오염과 벤치마크 누출은 어떻게 탐지하고 통제할 수 있는가?
5. 분산 학습, 정밀도 축소, 병렬화, 체크포인팅의 발전은 가능한 모델 규모를 어떻게 바꾸었는가?
6. 학습 비용과 에너지 사용을 비교할 때 어떤 단위와 공개 수준이 필요한가?
7. Mixture-of-Experts 같은 희소 구조는 품질, 지연 시간, 운영 비용 사이에서 어떤 절충을 제공하는가?

## 5. 후처리와 추론 능력

1. 지도 미세조정과 지시학습은 기본 모델의 행동을 어떻게 바꾸는가?
2. 인간 피드백 및 AI 피드백 기반 선호 최적화 방식은 각각 어떤 장단점을 갖는가?
3. 직접 선호 최적화 계열 방법은 전통적 강화학습 기반 방식과 무엇이 다른가?
4. 체인오브쏘트, 자기일관성, 검색, 도구 사용은 실제 능력 향상과 표현 방식 변화 중 무엇을 만들었는가?
5. 추론 단계에서 더 많은 연산을 쓰는 전략은 어떤 과제에서 효과적이며 비용은 어떻게 측정하는가?
6. 긴 문맥 길이는 실제 정보 활용 능력과 어떻게 구분해 평가해야 하는가?
7. 모델의 계획, 메모리, 도구 호출, 자율 실행을 구분하는 실용적 기준은 무엇인가?

## 6. 평가와 신뢰성

1. 시대별 대표 벤치마크는 어떤 능력을 측정했고 무엇을 놓쳤는가?
2. 벤치마크 포화와 데이터 오염 이후 모델 비교 방법은 어떻게 바뀌어야 하는가?
3. 정답률 외에 보정, 일관성, 근거성, 거부 정확도, 견고성을 어떻게 평가할 것인가?
4. 환각을 사실 오류, 인용 오류, 지시 불이행 등으로 어떻게 세분화할 것인가?
5. 다국어 및 저자원 언어 평가는 영어 중심 평가와 어떤 차이를 보여야 하는가?
6. 인간 평가와 자동 심사 모델 평가는 각각 어떤 편향과 재현성 문제를 갖는가?
7. 공개 리더보드와 실제 업무 성능이 다를 때 무엇을 우선할 것인가?

## 7. 멀티모달·에이전트·제품화

1. 텍스트 중심 LLM은 이미지, 음성, 영상, 행동을 다루는 모델로 어떻게 확장되고 있는가?
2. 네이티브 멀티모달 학습과 개별 모달리티 모델 결합 방식은 어떤 차이가 있는가?
3. 검색 증강 생성은 모델 내부 지식의 한계를 어디까지 보완하며 새로운 실패 모드는 무엇인가?
4. 함수 호출과 프로토콜 기반 도구 연결은 애플리케이션 구조를 어떻게 바꾸는가?
5. 에이전트 시스템의 자율성을 단계별로 어떻게 분류하고 각 단계의 안전장치를 어떻게 설계할 것인가?
6. 소형 온디바이스 모델과 대형 클라우드 모델의 역할 분담은 어떻게 변화하는가?
7. 지연 시간, 처리량, 컨텍스트 비용, 캐시, 배치가 실제 제품 선택에 어떤 영향을 주는가?

## 8. 오픈 생태계와 산업 구조

1. 오픈 소스, 오픈 웨이트, 오픈 데이터, 오픈 학습 코드를 어떤 기준으로 구분할 것인가?
2. 모델 라이선스의 사용 제한은 연구, 상업 이용, 파생 모델 배포에 어떤 영향을 주는가?
3. 독점 API와 자체 호스팅 모델의 품질, 비용, 통제권, 보안 절충은 무엇인가?
4. 증류, 양자화, 가지치기, 저랭크 미세조정은 모델 접근성을 어떻게 바꾸는가?
5. 컴퓨팅 자원, 반도체, 클라우드, 데이터 공급망은 모델 경쟁 구도에 어떤 영향을 주는가?
6. 모델 가격과 성능을 비교할 때 토큰당 가격 외에 어떤 총소유비용을 포함해야 하는가?
7. 연구기관, 빅테크, 스타트업, 오픈 커뮤니티의 역할은 시기별로 어떻게 변화했는가?

## 9. 안전·보안·사회·정책

1. 정렬, 안전, 보안, 책임 있는 AI는 각각 어떤 문제 범위를 가리키는가?
2. 프롬프트 인젝션, 데이터 유출, 모델 탈취, 공급망 공격을 어떻게 구분하고 평가할 것인가?
3. 탈옥 저항성과 과도한 거부 사이의 균형을 어떤 테스트로 측정할 것인가?
4. 편향, 차별, 허위정보, 노동시장 영향에 관한 주장은 어떤 증거 수준을 요구하는가?
5. 저작권, 개인정보, 데이터 출처 문제는 학습과 서비스 단계에서 각각 어떻게 다르게 나타나는가?
6. 국가별 규제와 표준의 차이가 모델 개발·배포·평가에 어떤 영향을 주는가?
7. 능력 평가와 위험 평가를 분리해야 하는 이유와 연결해야 하는 지점은 무엇인가?

## 10. 최신 동향 반복 점검

- 기준일: 2026-08-25

1. 기준일 직전 3개월 동안 공개된 주요 모델·기술 보고서·제품 중 추적할 항목은 무엇인가?
2. 각 발표의 핵심 변화는 새로운 학습법, 데이터, 아키텍처, 추론 방식, 제품 기능 중 어디에 해당하는가?
3. 발표자가 제시한 성능 향상은 독립 평가에서 재현되었는가?
4. 같은 기간에 비용, 지연 시간, 컨텍스트 길이, 멀티모달 성능은 어떤 방향으로 변했는가?
5. 오픈 웨이트 모델과 폐쇄형 모델의 격차는 어떤 과제에서 좁아지거나 벌어졌는가?
6. 새롭게 부상한 벤치마크는 기존 평가의 어떤 결함을 보완하려 하는가?
7. 추론 모델, 에이전트, 월드 모델, 온디바이스 모델 등 유행 용어 중 실질적 기술 변화를 나타내는 것은 무엇인가?
8. 최근 발표 중 아직 독립 검증이 부족하거나 마케팅 주장에 의존하는 것은 무엇인가?
9. 최근 6개월 사이 폐기되거나 약화된 가설·제품 전략·연구 방향은 무엇인가?
10. 다음 점검일까지 관찰할 선행 지표와 확인해야 할 사건은 무엇인가?

## 11. 종합과 서술 구조

1. LLM 발달사를 5~8개의 시대로 나눈다면 각 시대의 시작과 끝을 어떤 사건으로 정할 것인가?
2. 각 전환점은 이전 한계를 무엇으로 해결했고 어떤 새로운 한계를 만들었는가?
3. 성능 향상 가운데 규모 증가, 알고리즘 개선, 데이터 품질, 후처리의 기여를 어떻게 분리할 것인가?
4. 기술사와 제품사, 산업사, 정책사를 하나의 연표에서 어떻게 연결할 것인가?
5. 합의된 사실, 논쟁 중인 해석, 미래 전망을 문서에서 어떻게 명확히 구분할 것인가?
6. 현재 동향 중 일시적 유행과 구조적 변화를 판별할 기준은 무엇인가?
7. 조사 결과를 입문자용 개요, 기술 심화, 연표, 비교표 중 어떤 형태로 파생할 것인가?
