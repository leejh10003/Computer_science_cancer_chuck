# Comparing WSL Versions

## 확인 지점

- 버전별 기능 표와 교차 파일시스템 성능 예외: 원문 33–50행
- WSL 2의 목표와 구조: 원문 56–70행
- WSL 1을 선택할 수 있는 예외: 원문 85–104행

## 짧은 원문 발췌

> WSL 2 is the current default version when installing a Linux distribution.
